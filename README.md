# TraceLoom

TraceLoom is a lightweight offline analyzer for accelerator profiler timelines.
It is designed for distributed deep-learning performance work: take a profile
generated by the user's native CUDA/Nsight or Ascend/CANN stack, recover
semantic loop and communication structure, then emit tables, reports, and
Perfetto-compatible augmented timelines.

TraceLoom is intentionally not a runtime platform. It does not ship a Docker
environment, install accelerator drivers, or own workload launch in production.
It analyzes profiler output after the workload has run.

## Status

Current implementation:

- Ascend/CANN `msprof` SQLite profile discovery and analysis;
- semantic anchor timelines for compute and collective events;
- loop/repeat tree construction over semantic anchors;
- aux/prelude attribution for events that prepare the following anchor;
- CSV, JSON, Markdown, and static score-view outputs.

Planned public surface:

- generic Perfetto / Chrome Trace exporter with repeat, macro, anchor, and
  aux/prelude tracks;
- CUDA/Nsight input adapter;
- reference reproduction scripts for paper results;
- stable output schema and quality reports.

## Install

```bash
python3 -m pip install -e .
```

## Analyze An Ascend Profile

TraceLoom accepts either a run directory containing `msprof_raw` or the raw
profile directory directly:

```text
<run_dir>/msprof_raw/PROF_*/msprof_*.db
<raw_dir>/PROF_*/msprof_*.db
```

Run:

```bash
traceloom <run_dir-or-raw-msprof-dir> --out-dir out/traceloom
```

Without installation, use:

```bash
python3 -m traceloom <run_dir-or-raw-msprof-dir> --out-dir out/traceloom
```

## Outputs

Typical outputs include:

- `device_summary.csv`
- `meta.json`
- `*.anchor.tree.readable.md`
- `*.anchor.tree.json`
- `*.anchor.node_metrics.csv`
- `*.anchor.node_anchor_links.csv`
- `*.anchor.aux_slots.csv`
- `*.anchor.steps.csv`
- `*.anchor.symbols.csv`
- optional `*.anchor.score_view.html`

See [docs/output-schema.md](docs/output-schema.md) for the current contract.

## Paper Reproduction Model

The repository should not commit large profile databases. Reviewers reproduce
paper results by running the documented reference workload and profiler command
on their own multi-card CUDA or Ascend machine, then running TraceLoom on the
resulting profile directory.

Generated reproduction outputs are written under ignored `out/reproduce/` by
default:

```bash
python3 reproduce/run_reference.py analyze-msprof /path/to/msprof_or_run_dir --name reviewer_msprof
```

After installation, the same entry point is available as `traceloom-reproduce`.

See [docs/reference-reproduction.md](docs/reference-reproduction.md).

## Roadmap

The production visualization path is an augmented Perfetto timeline: TraceLoom
adds loop, repeat, macro, anchor, aux/prelude, and quality tracks that can be
opened next to the original profiler timeline.

See [docs/augmented-perfetto-timeline.md](docs/augmented-perfetto-timeline.md).
