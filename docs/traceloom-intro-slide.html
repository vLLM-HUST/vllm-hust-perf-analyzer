TraceLoom

离线加速器性能分析工具 MIT License

读取已采集的 Ascend/CANN msprof 产物，
将 profiler 事件整理成可读、可查、可比较的性能地图。

核心能力
  • ◆ 语义锚点树 — 从 profiler 事件中恢复循环结构和重复模式，生成可读 tree-map
  • ◆ 增强 SQLite DB — 原始表不动，注入 traceloom_* 视图，用 SQL 无限深挖
  • ◆ 成本归因模型 — compute / communication / aux / idle 逐节点拆分成本
  • ◆ 多卡对比 — 自动发现设备，支持按 device 过滤或全局 top-N 分析
  • ◆ 轻量离线 — 纯分析工具，不安装驱动、不依赖 Docker、不绑定运行时
推荐工作流
1 traceloom analyze /path/to/msprof_raw
↓
2 阅读 summary.md + tree-map.md
↓
3 定位热点 node (例如 N060)
↓
4 queries/*.sql 深挖事件与成本
输出产物
tree-map.md
性能地图 / 热点循环
*.augmented.db
增强 SQLite / SQL 查询
summary.md
全局概览 / 设备列表
queries/*.sql
内置分析查询脚本
vLLM-HUST · 分布式推理性能分析基础设施
