# Idle-evidence evaluation report

`tools/idle_evidence_evaluation.py` is the executable Coverage–FAR–overhead
report contract. It evaluates durations by exact interval intersection and
emits:

- explained coverage and false-attribution rate (FAR);
- a duration-weighted category confusion matrix;
- per-category over/under-attribution boundary error;
- the scanned epsilon multiplier, evidence-duration threshold, marker density,
  instrumentation level, and matched overhead metrics.

The evaluator rejects overlapping, missing, or out-of-gap prediction
partitions. A point can use inline predictions (controlled fixtures) or a
TraceLoom sidecar (`sidecar` plus optional `run_id`). The checked-in matrix is
explicitly `simulation/model`; its overhead values exercise the report schema
and do not replace runtime matched A/B.

For the conservative/balanced/aggressive checked-in points, reproducible
output reports respectively 26.961538%/88.461538%/100% Coverage and
0%/0%/11.576923% FAR. The JSON and markdown generated by the command below
also retain the complete duration-weighted confusion and boundary-error
tables. Generated reports stay outside the repository.

```sh
python3 tools/idle_evidence_evaluation.py \
  --manifest native/tests/fixtures/idle_evidence/evaluation_matrix.json \
  --json /tmp/idle-evidence-evaluation.json \
  --csv /tmp/idle-evidence-curve.csv \
  --markdown /tmp/idle-evidence-evaluation.md
```

For a runtime scan, keep the same request seed/config/capture boundary at every
point, use each accepted sidecar as the prediction, and supply matched
throughput, TTFT, ITL/TPOT, iteration-duration, device-productive-time, and
marker-count deltas in `overhead`. Runtime reports must carry an observation
label and must not be pooled with this controlled fixture matrix.
