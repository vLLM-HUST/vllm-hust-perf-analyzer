# Examples

This directory contains lightweight recipes, workload scaffolds, and the
checked kickstart profile used for a deterministic first run.

- `kickstart_smoke/`: real two-device Ascend/CANN `msprof` smoke profile and
  TraceLoom output for a deterministic first run.
- `configs/`: informational profiler recipes for Ascend/CANN and future CUDA
  adapters.
- `workloads/`: small workload scaffolds for local profiling and parser smoke
  checks.

For the fastest first run, start with `kickstart_smoke/`.
